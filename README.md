# NewUU Robotics Internship — Junior Track

Technical assessment submission for the Unitree G1 humanoid robot using MuJoCo.

## Part A — Human Motion to Robot
Reproduced a 10-second UltimateBots Studio motion on the 29-DOF G1 model.

- [Documentation](part_a/README.md)
- [Rendered video](part_a/motion.mp4)

## Part B — Circular Walking
Modified the pretrained G1 walking commands to produce circular motion.

- [Documentation](part_b/README.md)
- [Circular walking video](part_b/g1_circle.mp4)

Both demonstrations use the official [Unitree RL Gym repository](https://github.com/unitreerobotics/unitree_rl_gym).
